# Richieste di funzionalità degli utenti

Questa pagina raccoglie le richieste ricevute dagli utenti. Sono proposte per sviluppi futuri: non implicano che le funzioni siano già disponibili o pianificate per una specifica versione, salvo dove indicato.

## Italiano

### Realizzate nella 1.3.0 (in collaudo)

Piano di sviluppo: [PIANO_SVILUPPO_RICHIESTE.md](./PIANO_SVILUPPO_RICHIESTE.md).

- **Tema chiaro:** possibilità di scegliere un tema chiaro per l'interfaccia. → Impostazioni → *Aspetto*: Scuro, Chiaro o Sistema (solo Windows).
- **Scansione di frequenza:** scansione entro un intervallo configurabile, definito da una frequenza iniziale e una finale. → Pannello *Scansione* → *Intervallo* (solo Windows, con attivazione).
- **Processamento audio:** equalizzazione e filtri DSP, applicabili sia all'audio in ascolto sia all'audio registrato. → Pannello *DSP* della scheda Audio; si applica all'ascolto e alle nuove registrazioni, non a quelle già salvate (solo Windows, con attivazione).
- **Aggiunta mappa:** https://rx-tx.info/map-sdr-points → Pulsante in Impostazioni → Server che apre la mappa nel browser.

### Da valutare

Nessuna richiesta aperta.

## English

This page tracks feature requests received from users. These are proposals for future development; they do not mean the features are already available or scheduled for a specific release, unless stated.

### Delivered in 1.3.0 (under testing)

- **Light theme:** option to use a light interface theme. → Settings → *Appearance*: Dark, Light or System (Windows only).
- **Frequency scanning:** scan within a configurable range defined by start and end frequencies. → *Scan* panel → *Range* (Windows only, requires activation).
- **Audio processing:** equalization and DSP filters applicable to both live listening and recorded audio. → *DSP* panel in the Audio tab; applies to listening and new recordings, not to recordings already saved (Windows only, requires activation).
- **Add map:** https://rx-tx.info/map-sdr-points → Button in Settings → Server that opens the map in the browser.

### Open

No open requests.
